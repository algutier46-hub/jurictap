Principios SOLID
S - Single Responsibility
Una clase debe tener una sola responsabilidad.

O - Open Closed
Abierta para extension y cerrada para modificacion.

L - Liskov
Las clases hijas deben poder sustituir a la clase padre.

I - Interface Segregation
Interfaces pequeñas y especializadas.

D - Dependency Inversion
Depender de abstracciones y no de implementacio
